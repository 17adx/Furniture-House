## ✨ Features

- 🛒 **Cart Management:** Add to cart, remove items, and calculate totals dynamically.
- 🔍 **Dynamic Filtering:** Filter furniture products easily by categories to find exactly what you need.
- 📱 **Fully Responsive Design:** Optimized for all screen sizes (Desktop, Tablet, and Mobile).
- ⚡ **Fast Performance:** Built with Vite for incredibly fast Hot Module Replacement (HMR) and optimized build sizes.
- 🗄️ **Mock API Integration:** Uses simulated backend data to fetch products, categories, and inventory statuses efficiently.

---

## 🛠️ Tech Stack

- **Framework:** React.js
- **Build Tool:** Vite
- **Language:** JavaScript (ES6+)
- **Styling:** CSS3 / Tailwind CSS (Adjust if using standard CSS or modules)
- **State Management:** React Context API / Hooks
- **Routing:** React Router DOM
- **Deployment:** Vercel
